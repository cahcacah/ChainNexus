# ChainNexus

ChainNexus is a cloud-based, distributed computing platform featuring an auto-scaling ChainNexus Engine for seamless real-time data processing.

With ChainNexus, you get a lightweight tool that stays out of your way.

**What you get**

- ChainNexus is a cloud-based, distributed
- computing platform featuring an auto-scaling
- ChainNexus Engine for seamless real-time

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/ChainNexus.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

ChainNexus is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
